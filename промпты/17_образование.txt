Найди в приложенных документах все места учёбы Субъекта.
Для каждого места обучения определи: период, название образовательного учреждения, направление обучения.
Правила:
Период учёбы указывай в формате ГГГГ-ГГГГ (например, 1999-2001). Если в источнике указан только один год, связанный с местом учёбы, считай, что это год окончания. Если в разных источниках указаны разные годы для одного и того же места учёбы, но интервал между ними меньше 5 лет, считай более ранний годом начала, более поздний — годом окончания. Если известен только один год и он не старше 4 лет от текущего (2026), вместо года окончания указывай «настоящее время».
Поле «направление обучения» должно содержать в одной строке (при наличии): уровень обучения (например, высшее образование, среднее профессиональное образование), факультет, специальность, квалификация, форма обучения, номер диплома. Элементы разделять переносом строки (\n). Если какого-то элемента нет в документах — не добавлять его. Если ни один элемент не найден — оставить поле пустым.
Если одно и то же место учёбы упоминается в нескольких документах — объединить в одну запись, составив наиболее полный вариант из всех упоминаний.
Отсортировать по дате начала учёбы: сначала самое позднее место учёбы, последним — самое раннее.
Верни ответ строго в формате JSON. Каждое место учёбы — это один объект в массиве со следующими полями: период, наименование учебного заведения, направление обучения.
Пример:
{
  "данные": [
    {
      "период": "2020-настоящее время",
      "наименование учебного заведения": "РГГУ",
      "направление обучения": "Магистратура\nЮридический факультет\nЮриспруденция"
    },
    {
      "период": "1999-2003",
      "наименование учебного заведения": "Московский государственный университет им. М.В. Ломоносова",
      "направление обучения": "Высшее образование\nЭкономический факультет\nЭкономист\nДиплом 123456 от 12.10.2003"
    },
    {
      "период": "1995",
      "наименование учебного заведения": "Школа №15 г. Москва",
      "направление обучения": ""
    }
  ]
}
Если информация о местах учёбы не найдена — верни пустой массив: {"данные": []}.
Не добавляй пояснений, комментариев или текста вне JSON.

КРИТИЧЕСКИ ВАЖНО: ответ должен содержать только JSON с единственным ключом "данные". Не используй другие ключи. 
Не используй английские названия полей. 
Не добавляй полей, которых нет в примере.
