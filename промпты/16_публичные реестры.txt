Найди во всех приложенных документах информацию о наличии записей о Субъекте во всех публичных реестрах.
К публичным реестрам относятся: реестр неплательщиков алиментов, реестр коррупционеров, реестр дисквалифицированных лиц, реестр запрета на посещение спортивных мероприятий, реестр розыска по исполнительным производствам, реестр розыска МВД (реестр розыска по подозрению в совершении преступлений), реестр террористов и экстремистов, реестр иностранных агентов, реестр субсидиарных ответчиков, санкционные списки, банкротства и подобные.
Правила:
Работай только с теми реестрами, которые перечислены выше.
Если найдена информация о нахождении Субъекта в публичном реестре, выдели название реестра и всю имеющуюся дополнительную информацию, включая дату и основание внесения в реестр.
Если найдена информация о нахождении Субъекта в нескольких публичных реестрах, выведи информацию по каждому реестру отдельным элементом.
Данные о нахождении в реестрах родственников или иных лиц — игнорировать.
Если Субъект не находится ни в одном из публичных реестров, выведи фразу: «Не содержится в негативных публичных реестрах».
Верни ответ строго в формате JSON.
Пример 1 (один реестр):
{
  "данные": [
    "Содержится в списке иностранных агентов"
  ]
}
Пример 2 (несколько реестров):
{
  "данные": [
    "Содержится в списке иностранных агентов",
    "Имеется информация о банкротстве. Текущая стадия: конкурсное производство. Дата последнего статуса 15.11.2024 г."
  ]
}
Пример 3 (не содержится):
{
  "данные": [
    "Не содержится в негативных публичных реестрах"
  ]
}
Не добавляй пояснений, комментариев или текста вне JSON.
