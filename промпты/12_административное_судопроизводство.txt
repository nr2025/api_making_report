Найди во всех приложенных документах информацию об участии Субъекта в административных разбирательствах.
Правила:
Если найдено несколько фактов участия Субъекта в административных разбирательствах, выведи каждое дело отдельно.
По каждому административному разбирательству укажи подробно всю имеющуюся информацию: орган (судебный или правоохранительный), номер дела, дату, роль Субъекта, статью, фабулу (суть), результат по делу. Если какой-либо из элементов не найден в документах — пропусти его без пояснений.
Данные об административных делах в отношении родственников или иных лиц — игнорировать.
Если не установлено участия Субъекта в административных разбирательствах, выведи фразу: «Судебные дела с похожими реквизитами участников не найдены.».
Верни ответ строго в формате JSON.
Пример 1 (одно дело, все элементы):
{
  "данные": [
    "Орган: Судебный участок № 5 г. Москвы\nНомер дела: 1255/2012\nДата: 01.02.2012\nРоль: лицо, совершившее правонарушение\nСтатья: ст. 20.1 КоАП РФ\nФабула: Иванов И.И. выражался нецензурной бранью в парке\nРезультат по делу: назначено наказание в виде административного штрафа"
  ]
}
Пример 2 (одно дело, часть элементов отсутствует):
{
  "данные": [
    "Дата: 01.02.2012\nРоль: лицо, совершившее правонарушение\nФабула: правонарушение в сфере транспортной безопасности (нарушение ПДД)\nРезультат по делу: назначено наказание в виде административного штрафа"
  ]
}
Пример 3 (несколько дел):
{
  "данные": [
    "Номер дела: 1255/2012\nДата: 01.02.2012\nРоль: лицо, совершившее правонарушение\nСтатья: ст. 20.1 КоАП РФ\nФабула: Иванов И.И. выражался нецензурной бранью в парке\nРезультат по делу: назначено наказание в виде административного штрафа",
    "Дата: 01.02.2012\nРоль: лицо, совершившее правонарушение\nФабула: правонарушение в сфере транспортной безопасности (нарушение ПДД)\nРезультат по делу: назначено наказание в виде административного штрафа"
  ]
}
Пример 4 (не найдено):
{
  "данные": [
    "Судебные дела с похожими реквизитами участников не найдены."
  ]
}
Не добавляй пояснений, комментариев или текста вне JSON.
