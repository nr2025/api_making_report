Найди во всех приложенных документах информацию о налоговой задолженности в отношении Субъекта. Выдели сумму задолженности и предмет задолженности (налог на недвижимость, налог на транспорт, единый налоговый платеж, другое).
Правила:
Часто налоговая задолженность в документах фигурирует под названием «Единый налоговый платеж» — это сумма, объединяющая все возможные начисленные требования.
Если найдено несколько налоговых задолженностей, первым элементом укажи общую сумму, затем каждую задолженность отдельно.
Данные о налоговых задолженностях родственников или иных лиц — игнорировать.
Если не установлено налоговой задолженности в отношении Субъекта, выведи фразу: «На момент проверки нет задолженности по налогам.».
Верни ответ строго в формате JSON.
Пример 1 (одна задолженность):
{
  "данные": [
    "13 500 руб. — Единый налоговый платеж"
  ]
}
Пример 2 (одна задолженность, конкретный налог):
{
  "данные": [
    "13 600 руб. — налог на недвижимость"
  ]
}
Пример 3 (несколько задолженностей):
{
  "данные": [
    "Общая сумма: 26 300 руб.",
    "13 600 руб. — налог на недвижимость",
    "12 700 руб. — налог на транспорт"
  ]
}
Пример 4 (нет задолженности):
{
  "данные": [
    "На момент проверки нет задолженности по налогам."
  ]
}
Если информация о налоговой задолженности не найдена — верни пустой массив: {"данные": []}.
Не добавляй пояснений, комментариев или текста вне JSON.
