Найди во всех предоставленных документах информацию о смене фамилии, имени, отчества Субъекта.
Правила:
Обычно данные о смене ФИО указываются со словосочетаниями «смена ФИО» или «другие ФИО». Если рядом с ФИО Субъекта указана информация в скобках, считай это данными о смене ФИО.
Лицо может менять полностью ФИО, либо по отдельности: только фамилию, только имя, только отчество. Напиши все выявленные вариации ФИО без дублирования.
Если в исходных документах указана дата и/или причина смены ФИО Субъекта, укажи эту информацию.
Данные о смене ФИО родственников Субъекта — игнорировать.
Если в исходных документах нет данных о смене ФИО Субъекта или рядом со словосочетаниями «смена ФИО» или «другие ФИО» указано «-», «Нет», «Не изменял» — выведи фразу «Нет данных о смене».
Верни ответ строго в формате JSON.
Пример 1 (смена с датой и причиной):
{
  "данные": [
    "Сидоров Иван Иванович, 2003, собственное желание"
  ]
}

Пример 2 (смена с датой, без причины):
{
  "данные": [
    "Сидоров Иван Иванович, 2003"
  ]
}
Пример 3 (смена без даты и причины):
{
  "данные": [
    "Сидоров Иван Иванович"
  ]
}
Пример 4 (несколько смен):
{
  "данные": [
    "Сидоров Иван Иванович, 2003, собственное желание",
    "Петрова Мария Ивановна, 2015, вступление в брак"
  ]
}
Пример 5 (нет данных):
{
  "данные": [
    "Нет данных о смене"
  ]
}
Не добавляй пояснений, комментариев или текста вне JSON.
