Найди во всех приложенных документах информацию об участии Субъекта в гражданских судебных разбирательствах.
Правила:
Если найдено несколько фактов участия Субъекта в гражданских разбирательствах, выведи каждое дело отдельно.
По каждому гражданскому разбирательству укажи подробно всю имеющуюся информацию: судебный орган, номер дела, дату, ответчика (-ов), истца (-ов), фабулу (суть), результат по делу. 
Также, рядом с фамилией Субъекта в числе истцов или ответчиков указать в скобках (кандидат).
Если какой-либо из элементов не найден в документах — пропусти его без пояснений.
Если не установлено участия Субъекта в гражданских разбирательствах, выведи фразу: «Судебные дела с похожими реквизитами участников не найдены.».
Верни ответ строго в формате JSON.
Пример 1 (одно дело, один истец, один ответчик):
{
  "данные": [
    "Орган: Судебный участок № 5 г. Москвы\nНомер дела: 1255/2012\nДата: 01.02.2012\nИстец: Иванова М.В.\nОтветчик: Иванов П.Р. (кандидат)\nФабула: Иванов П.Р. 
подал иск о расторжении брака супругов имеющих детей\nРезультат по делу: иск удовлетворен"
  ]
}
Пример 2 (одно дело, несколько истцов, несколько ответчиков):
{
  "данные": [
    "Дата: 01.02.2012\\nИстцы: ООО "Коллекторское агентство", ООО "Банк Солют"\nОтветчики: Иванов П.Р. (кандидат), Иванова М.В.\nФабула: иск о взыскании просроченной креддитной задолженности\nРезультат по делу: иск удовлетворен"
  ]
}
Пример 3 (не найдено):
{
  "данные": [
    "Судебные дела с похожими реквизитами участников не найдены."
  ]
}
Не добавляй пояснений, комментариев или текста вне JSON.
