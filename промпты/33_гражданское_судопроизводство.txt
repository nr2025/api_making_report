Найди во всех приложенных документах информацию об участии Субъекта в гражданских судебных разбирательствах.
Правила:
Если найдено несколько фактов участия Субъекта в гражданских разбирательствах, выведи каждое дело отдельным элементом массива.
По каждому гражданскому разбирательству укажи подробно всю имеющуюся информацию: судебный орган, номер дела, дату, истца (-ов), ответчика (-ов), иных лиц, фабулу (суть), результат по делу. Если какой-либо из элементов не найден в документах — пропусти его без пояснений.
Рядом с фамилией Субъекта в числе истцов, ответчиков или иных лиц укажи в скобках: (кандидат).
Каждый элемент массива — строка (не объект). Внутри строки отдельные сведения разделяй переносом строки \n в формате «Название: значение». Не используй вложенные объекты и поля.
Если не установлено участия Субъекта в гражданских разбирательствах, выведи фразу: «Судебные дела с похожими реквизитами участников не найдены.».
Верни ответ строго в формате JSON.
Пример 1 (одно дело): 
{
  "данные": [
    "Орган: Судебный участок № 5 г. Москвы\nНомер дела: 1255/2012\nДата: 01.02.2012\nИстец: Иванова М.В.\nОтветчик: Иванов П.Р. (кандидат)\nФабула: иск о расторжении брака супругов, имеющих детей\nРезультат по делу: иск удовлетворён"
  ]
}
Пример 2 (несколько истцов и ответчиков):
{
  "данные": [
    "Дата: 01.02.2012\nИстцы: ООО «Коллекторское агентство», ООО «Банк Солют»\nОтветчики: Иванов П.Р. (кандидат), Иванова М.В.\nФабула: иск о взыскании просроченной кредитной задолженности\nРезультат по делу: иск удовлетворён"
  ]
}
Пример 3 (не найдено):
{
  "данные": [
    "Судебные дела с похожими реквизитами участников не найдены."
  ]
}
Не добавляй пояснений, комментариев или текста вне JSON.
