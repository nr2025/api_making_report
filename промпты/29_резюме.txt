Найди во всех представленных документах информацию о резюме Субъекта. Это может быть как файл резюме, так и упоминание в составе какого-либо массива информации о когда-либо размещённом резюме Субъекта.
Для каждого резюме выдели четыре поля: дату обновления, желаемую должность, желаемый оклад, статус. Сведений о любом из полей может не быть.
Определение статуса:
Статус может быть прямо указан в резюме (например: «активно ищет работу», «рассматривает предложения», «не ищет работу») — в этом случае используй указанный статус.
Если статус прямо не указан, определи его по дате обновления: если резюме обновлялось в последние 2 года — статус «-»; если сведений о дате обновления нет или резюме обновлялось более 2 лет назад — статус «Предположительно архивное резюме».
Заполнение полей «дата обновления», «желаемая должность», «желаемый оклад»: если элемент отсутствует в документах — выведи «-».
Сортировка: по убыванию даты обновления (сначала самые свежие), записи без даты обновления — в конце.
Каждое резюме — это один объект в массиве со следующими полями: дата обновления, желаемая должность, желаемый оклад, статус.
Если информации о резюме Субъекта не найдено, верни массив с одной строкой: 
{"данные": ["Нет открытых резюме на кадровых порталах"]}
Верни ответ строго в формате JSON.
Пример 1 (есть резюме):
{
  "данные": [
    {
      "дата обновления": "12.08.2024",
      "желаемая должность": "Начальник отдела АХО",
      "желаемый оклад": "-",
      "статус": "активно ищет работу"
    },
    {
      "дата обновления": "12.07.2023",
      "желаемая должность": "Кладовщик отдела АХО",
      "желаемый оклад": "-",
      "статус": "-"
    },
    {
      "дата обновления": "11.05.2015",
      "желаемая должность": "Курьер",
      "желаемый оклад": "15000 руб.",
      "статус": "Предположительно архивное резюме"
    },
    {
      "дата обновления": "-",
      "желаемая должность": "Курьер-водитель",
      "желаемый оклад": "-",
      "статус": "Предположительно архивное резюме"
    }
  ]
}
Пример 2 (нет резюме):
{
  "данные": [
    "Нет открытых резюме на кадровых порталах"
  ]
}
Не добавляй пояснений, комментариев или текста вне JSON.
