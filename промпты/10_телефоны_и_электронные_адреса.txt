REASONING: medium

Найди во всех приложенных документах информацию о контактных данных Субъекта.
Правила:
К контактным данным относятся номер телефона и электронная почта.
Данные о контактах родственников или иных лиц — игнорировать.
Номера телефонов приводить к единому формату +7(XXX)XXX-XX-XX.
Сначала указывать все телефоны, затем все электронные почты. Первый телефон — самый часто встречающийся в документах. Аналогично с электронной почтой.
Верни ответ строго в формате JSON.
Пример 1 (один телефон, одна почта):
{
  "данные": [
    "Телефон: +7(911)111-11-11",
    "E-mail: ss12@mail.ru"
  ]
}
Пример 2 (два телефона, одна почта):
{
  "данные": [
    "Телефон: +7(911)111-11-11",
    "+7(922)222-22-22",
    "E-mail: ss12@mail.ru"
  ]
}
Пример 3 (один телефон, две почты):
{
  "данные": [
    "Телефон: +7(911)111-11-11",
    "E-mail: ss12@mail.ru",
    "ss11@gmail.com"
  ]
}
Пример 4 (несколько телефонов, несколько почт):
{
  "данные": [
    "Телефон: +7(911)111-11-11",
    "+7(922)222-22-22",
    "E-mail: ss12@mail.ru",
    "ss11@gmail.com"
  ]
}
Если контактные данные не найдены — верни пустой массив: {"данные": []}.
Не добавляй пояснений, комментариев или текста вне JSON.
