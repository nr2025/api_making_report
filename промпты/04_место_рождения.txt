REASONING: medium

Найди во всех приложенных документах информацию о месте рождения Субъекта. Выдели из информации о месте рождения населённый пункт, район и регион. 
Соедини в одну строку через запятую.
Правила:
Обычно место рождения указано рядом с пометкой «Место рождения» либо рядом с датой рождения Субъекта.
Если найдено несколько разных данных о месте рождения, считай верным то, что встречается чаще, или то, что указано рядом с пометкой «Место рождения».
Если какой-либо из элементов (населённый пункт, район, регион) не указан — пропусти его.
Указывай элементы строго в именительном падеже, названия строго с заглавной буквы.
Верни ответ строго в формате JSON.
Пример 1 (все элементы):
{
  "данные": [
    "д. Мамликасы, Цивильский р-н, Чувашская Республика"
  ]
}
Пример 2 (без района):
{
  "данные": [
    "д. Мамликасы, Чувашская Республика"
  ]
}
Пример 3 (город и регион):
{
  "данные": [
    "г. Чебоксары, Чувашская Республика"
  ]
}
Пример 4 (только город-регион):
{
  "данные": [
    "г. Москва"
  ]
}
Если место рождения не найдено — верни пустой массив: {"данные": []}.
