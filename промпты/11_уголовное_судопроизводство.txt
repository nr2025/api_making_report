Найди во всех приложенных документах информацию об участии Субъекта в уголовных разбирательствах или об отношении субъекта к уголовным преступлениям.
Правила:
Если найдено несколько фактов участия Субъекта в уголовных разбирательствах, выведи каждое дело отдельно.
Информация в исходных документах может быть описана в разных форматах: официальные / судебные данных, описательный информационный блок из СМИ, другое. Всю информацию, указывающую на отношение Субъекта к уголовному преступлению надо использовать.  

По каждому уголовному разбирательству укажи подробно всю имеющуюся информацию: судебный или правоохранительный орган, номер дела, дату, роль Субъекта, статью, фабулу (суть), результат по делу. Если какой-либо из элементов не найден в документах — пропусти его без пояснений.
Данные об уголовных делах в отношении родственников или иных лиц — игнорировать.
Если не установлено участия Субъекта в уголовных разбирательствах, выведи фразу: «Судебные дела с похожими реквизитами участников не найдены.».
Верни ответ строго в формате JSON.
Пример 1 (одно дело, все элементы):
{
  "данные": [
    "Орган: Головинский районный суд г. Москвы\nНомер дела: 1255/2012\nДата: 01.02.2012\nРоль: обвиняемый\nСтатья: ст. 158 УК РФ\nФабула: Иванов И.И. украл печенье из продуктового магазина\nРезультат по делу: назначено наказание в виде уголовного штрафа"
  ]
}
Пример 2 (одно дело, часть элементов отсутствует):
{ "данные": [ "Дата: 2024 г.\nРоль: обвиняемый\nФабула: Иванов И.И. 15.11.2024 г. доставлялся в отделение полиции в связи с подозрением в совершении коррупционного преступления в качестве директора ООО «Ромашка»" ] }
Пример 3 (несколько дел):
{
  "данные": [
    "Орган: Головинский районный суд г. Москвы\nНомер дела: 1255/2012\nДата: 01.02.2012\nРоль: обвиняемый\nСтатья: ст. 158 УК РФ\nФабула: Иванов И.И. украл печенье из продуктового магазина\nРезультат по делу: назначено наказание в виде уголовного штрафа",
    "Дата: 2024 г.\nРоль: обвиняемый\nФабула: Иванов И.И. 15.11.2024 г. доставлялся в отделение полиции в связи с подозрением в совершении коррупционного преступления в качестве директора ООО «Ромашка»"
  ]
}
Пример 4 (не найдено):
{
  "данные": [
    "Судебные дела с похожими реквизитами участников не найдены."
  ]
}
Не добавляй пояснений, комментариев или текста вне JSON.
