REASONING: medium

Найди во всех представленных документах ссылку на социальную сеть «Одноклассники» Субъекта либо ID Одноклассники Субъекта.
Поиск:
Обычно ссылка на социальную сеть «Одноклассники» содержит «ok.ru».
Обычно ID Одноклассники упоминается рядом с пометками: «Одноклассники», «ОК», «Ok», «Odnoklassniki», «ID» в числовом формате, длина до 12 цифр.
Если ID указан после пометки «ID», проверь, не относится ли он к другим социальным сетям: «Telegram» («Телеграм»), «Вконтакте» («Vkontakte», «ВК», «VK», «vk.com»), «Фейсбук» («Facebook», «Fb», «ФБ», «facebook.com», «fb.com»). Если относится к другой сети — игнорировать.
Правила извлечения:
Если найдена ссылка с содержанием «ok.ru» — вывести её.
Номер телефона не является ID Одноклассники. Игнорировать строки, содержащие плюс, дефисы, скобки.
Если один и тот же ID или ссылка встречается несколько раз — вывести один раз, без дублирования.
Данные о социальных сетях родственников или иных лиц — игнорировать.
Верни ответ строго в формате JSON.
Пример 1 (одна ссылка):
{
  "данные": [
    "https://ok.ru/profile/077780024833"
  ]
}
Пример 2 (несколько значений):
{
  "данные": [
    "https://ok.ru/profile/077780024833",
    "077780024833"
  ]
}
Если ссылка или ID Одноклассники не найдены — верни пустой массив: {"данные": []}.
Не добавляй пояснений, комментариев или текста вне JSON.
