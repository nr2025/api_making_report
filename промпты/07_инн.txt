Найди во всех приложенных документах информацию об ИНН Субъекта.
Обычно данные об ИНН указаны рядом с пометкой «ИНН». ИНН физического лица состоит строго из двенадцати цифр. Любые номера, состоящие не из 12 цифр, игнорировать.
Обычно у Субъекта должен быть один ИНН. Однако, если в документах указано два и более, включи в ответ все варианты.
Если в документах встречается информация о том, что Субъект зарегистрирован как самозанятый, добавь эту информацию.
Если ИНН не найден — верни пустой массив: {"данные": []}.
Верни ответ строго в формате JSON.
Пример 1 (один ИНН):
{
  "данные": [
    "123456789123"
  ]
}
Пример 2 (два ИНН):
{
  "данные": [
    "123456789123",
    "123456734686"
  ]
}
Пример 3 (ИНН + самозанятый):
{
  "данные": [
    "123456789123",
    "Имеет статус самозанятого"
  ]
}
Пример 4 (два ИНН + самозанятый):
{
  "данные": [
    "123456789123",
    "123456734686",
    "Имеет статус самозанятого"
  ]
}
Не добавляй пояснений, комментариев или текста вне JSON.
