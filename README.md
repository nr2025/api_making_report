# API Making Report

Скрипт для поэтапной обработки юридических документов через LLM (Ollama API) и сборки итогового Word-отчета по шаблону.

## Что делает скрипт

- Читает документы по субъекту из папки `вход/<Имя Субъекта>/`
- Обрабатывает все промпты из папки `промпты/` по номеру (`01_...`, `02_...`, ...)
- Сохраняет ответ каждого шага в `выход/<Имя Субъекта>/промежуточные/*.json`
- Для последнего промпта использует результаты предыдущих JSON-шагов
- Собирает итоговый `.docx` из `шаблон.docx`

## Поддерживаемые форматы документов

- `.docx` — извлечение текста
- `.doc` — конвертация в `.docx` через Microsoft Word (win32com), затем извлечение текста
- `.pdf`:
  - текстовый PDF -> извлечение текста через PyMuPDF
  - PDF-скан -> конвертация страниц в изображения и отправка в мультимодальную модель
- `.jpg`, `.jpeg`, `.png` — отправка как изображения в модель

`субъект.txt` не обрабатывается как документ, используется только как источник ФИО.

## Структура проекта

```text
API_making_report/
├── run_report_mvp.py
├── настройки.yaml
├── шаблон.docx
├── промпты/
├── вход/
└── выход/
```

## Настройки

Минимум в `настройки.yaml`:

```yaml
api_url: http://localhost:11434
model: qwen2.5vl:72b-32k
```

Опционально можно добавить:

- `input_dir`
- `prompts_dir`
- `output_dir`
- `template_path`
- `num_predict` (минимум 16384)
- `request_timeout_sec`
- `max_json_retries`

## Установка зависимостей

```bash
python -m pip install pymupdf python-docx pywin32
```

## Запуск

```bash
python run_report_mvp.py
```

После выполнения результат будет в:

- `выход/<Имя Субъекта>/промежуточные/` — JSON по шагам
- `выход/<Имя Субъекта>/<Имя Субъекта>.docx` — итоговый Word-отчет

## Примечания

- Скрипт не удаляет файлы автоматически.
- Для обработки `.doc` на Windows должен быть установлен Microsoft Word.
